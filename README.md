# WiFi TV

Installers and automatic updates for WiFi TV (the laptop app and the Android phone app).

- **Laptop (Windows):** download `WiFi-TV-Setup-<version>.exe` from the latest release and install it. After that, WiFi TV updates itself.
- **Phone (Android):** download `WiFi-TV.apk` from the latest release. The app tells you when a new version is out (Settings > Update).

This repository holds only the release files.
